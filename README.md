# alexwebstudio

Сайт студии на **Next.js 16 (App Router, JavaScript)** с анимациями **GSAP** и плавным скроллом **Lenis**.

```bash
npm install
npm run dev      # локально: http://localhost:3000
npm run build    # сборка для продакшена
npm start        # запуск собранной версии
```

## Как управлять контентом

Весь текст и портфолио лежат в папке `content/` — код трогать не нужно.

### Добавить проект в портфолио

1. Положите скриншот в `public/portfolio/` (JPG или PNG, ширина до 1600 px).
2. Скопируйте `content/projects/_template.md` и назовите файл адресом страницы латиницей,
   например `content/projects/coffee-house.md` → страница `/portfolio/coffee-house`.
3. Заполните поля в шапке файла (между `---`) и напишите описание ниже.
4. Готово: проект появится в портфолио, получит свою страницу и попадёт в `sitemap.xml`.

Важные поля:

| Поле | Что значит |
|---|---|
| `status` | `real` — реальный заказ, `concept` — концепт, `template` — шаблон, `fan` — фан-проект. На сайте статус подписан у каждой работы. |
| `kind` | группа для фильтра: `landing`, `multi`, `shop`, `invite`, `business`, `fan` |
| `featured: true` | показывать проект в блоке «Избранные работы» на главной |
| `order` | порядок: чем меньше число, тем выше |
| `task`, `result` | задача клиента и итог — заполняйте **только если они подтверждены**, иначе блок не выводится |
| `features` | что есть на сайте — список |
| `gallery` | дополнительные скриншоты |

Файлы, чьё имя начинается с `_`, на сайт не попадают.

### Остальные тексты

| Файл | Что внутри |
|---|---|
| `content/settings.json` | адрес сайта и ссылки на соцсети, **включая Telegram-канал** (`telegramChannel`) |
| `content/services.json` | услуги: цены, сроки, что входит. У каждой услуги своя страница `/services/<slug>`. Поле `kinds` связывает услугу с типами проектов (`kind` в портфолио) — на странице услуги автоматически показываются подходящие работы. Поле `slug` — адрес страницы |
| `content/faq.json` | частые вопросы на главной |
| `content/products.json` | «Мои полезные работы». У каждого продукта своя страница `/products/<slug>`. Поля: `task` (какую задачу решает), `audience` (кому подходит), `benefits` (возможности), `kinds` (связь с типами проектов — на странице продукта показываются подходящие работы), `slug` — адрес страницы |
| `content/reviews.json` | отзывы |
| `content/about.json` | «Обо мне»: текст, стек, этапы, принципы, преимущества, **команда** (`team` — добавьте людей, и появится сетка) |
| `content/quiz.json` | варианты ответов в квизе |
| `content/join.json` | направления в форме «Вступить в команду» |
| `content/privacy.js` | текст политики конфиденциальности (страница `/privacy`) — правьте разделы прямо здесь |

## Заявки в Telegram

Квиз и форма «Вступить в команду» отправляют заявки на сервер (`/api/lead`), а он — в Telegram.
Токен хранится на сервере и не виден в коде страницы.

1. `@BotFather` → `/newbot` → получите токен; `@userinfobot` → узнайте свой `chat_id`.
2. Локально: скопируйте `.env.example` в `.env.local` и впишите значения.
3. **На хостинге (Vercel):** `.env.local` в деплой НЕ попадает (он в `.gitignore`).
   Задайте те же переменные в **Project → Settings → Environment Variables**
   (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) для окружения **Production** (и Preview),
   затем **Redeploy**. Без этого формы на продакшене не отправляют заявки —
   это и есть причина «на localhost работает, на проде нет».
4. Сайт должен быть задеплоен как **Next.js-приложение** (serverless-функции), а не
   как статический экспорт — иначе маршрут `/api/lead` не запустится.

Если заявка не уходит, посмотрите логи функции `/api/lead` у хостинга: там будет
понятная причина (не заданы переменные окружения или ошибка Telegram API).

Пока переменные не заданы, формы не делают вид, что всё отправилось: они сообщают, что автоматическая
отправка недоступна, и предлагают отправить готовый текст заявки в WhatsApp или Telegram.

## Шрифты

- Заголовки — **Tektur** (Google Fonts, с кириллицей), подключён в `app/fonts.js`,
  применяется только к заголовкам (`.hx`).
- Основной текст — **Onest**, логотип и крупные декоративные цифры — **Unbounded**,
  подписи — **JetBrains Mono** (не менялись).

Чтобы сменить шрифт заголовков на другой — поменяйте импорт и вызов `headingFont`
в `app/fonts.js` (хорошие варианты с кириллицей: Wix Madefor Display, Geologica).

## Структура

```
app/            страницы (/, /portfolio, /portfolio/[slug], /services/[slug], /products/[slug], /about, /reviews, /join, /brief, 404) и API
components/     компоненты: шапка, меню, подвал, заголовки, пиксели, квиз, формы…
content/        весь контент сайта
lib/            чтение контента, отправка заявок, общие утилиты
public/         изображения
```
